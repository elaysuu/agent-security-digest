# This Week in AI-Agent Security Advisories

A weekly, auto-generated digest of security advisories affecting MCP servers, MCP SDKs and AI-agent / LLM tooling on npm and PyPI. Every advisory ID is checked against OSV at generation time; anything not in OSV or withdrawn is dropped.

- Issues: `issues/NNN.md` (+ `.json`), RSS: `issues/feed.xml`
- Runs every Monday 06:00 UTC via `.github/workflows/weekly.yml`
- Sponsor slot: one per issue, $29/week. Sponsor text lives in `sponsor.json` (`{"name","text","url"}`); delete it after the week.
- Book the sponsor slot: https://setrov.gumroad.com/l/digest-sponsor
- Block these in CI: https://github.com/elaysuu/agent-advisory-gate

Data: AKRENON Security "MCP Security Vulnerabilities Dataset" (https://data.akrenon.com/mcp-advisories/), CC BY 4.0, filtered/reformatted; GitHub Advisory Database (CC BY 4.0); OSV.dev. Code: MIT.
